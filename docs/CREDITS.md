# Credits

## Characters

Every character (bosses, dealers, room hosts and you) is built from **Modular Characters** by Kenney
([kenney.nl](https://kenney.nl/assets/modular-characters)), released under
[CC0](https://creativecommons.org/publicdomain/zero/1.0/). Hats, glasses and other accessories, the recolouring
and the animation rig were added for this game (see `Tools/Art`).
